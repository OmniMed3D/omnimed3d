OmniMed3D GitHub

Research prototype

3D medical imaging that runs entirely in your browser

OmniMed3D renders CT and MR volumes with WebGPU and runs AI segmentation on your own device. There is nothing to install, and your scans never leave your machine.

Open the demo View on GitHub

The demo loads a public, de-identified chest CT. Needs a WebGPU-capable browser, such as recent Chrome on desktop or Android.

This browser doesn't expose WebGPU, so the viewer can't start here. Try a recent version of Chrome.

Nothing to install

Open a link and load a scan. No plugin, no desktop app, no IT setup.

Nothing uploaded

DICOM parsing, AI inference, and rendering all happen on your device. No server ever sees the data.

Runs without a network

Once the app has loaded, parsing, rendering, and segmentation need no network connection.

AI segmentation that never blocks the view

The volume renders the moment it loads. A lung segmentation model runs in the browser with ONNX Runtime Web, and its mask fills in slice by slice on top of the image you're already exploring.

How it works

  1. Your DICOM files Picked from disk. Never uploaded.
  2. Parse Worker C++ DICOM parser compiled to WASM builds the HU volume.
  3. Engine Renders the volume with WebGPU right away.
  4. Inference Worker Segments slices in parallel and streams the mask to the engine.

Built with

  • WebGPU volume raymarching
  • C++20 engine compiled to WASM with Emscripten
  • Slang shaders cross-compiled to WGSL
  • ONNX Runtime Web for on-device inference

OmniMed3D is research prototype software. It is not a certified clinical device and is not for diagnostic use.

Demo data: LIDC-IDRI (CC BY 3.0) and UPENN-GBM (CC BY 4.0), both from The Cancer Imaging Archive. Full citations are shown in the viewer's demo panel.
